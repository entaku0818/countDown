# CountDown v1.0 構想 — 「楽しみまでの道のり」アプリへ

## 1. ターゲット
- 大きな楽しみ（結婚式・旅行・出産・ライブ・受験明け等）を **待っている人**
- 待つ時間そのものを楽しみたい／準備を段階的に進めたい人
- 例：結婚式（ゴール）の中に「前撮り」「招待状発送」「ドレス決定」「ネイル予約」などの小さなゴールがある

## 3. コンセプト
> **「楽しみまでの道のりを、一歩ずつ味わうカウントダウン」**

### 3.1 データ構造：ゴール（エピック）とステップ
- `Event` に `parentId: UUID?` を追加し、**ツリー構造（階層の深さは無制限）**にする
  - 親なし＝**ゴール**（結婚式）
  - 子＝**ステップ**（前撮り）→ さらにその子も作れる（前撮り → 衣装合わせ）
- ステップには「完了」チェックを付ける（日付が来たら自動完了 or 手動完了）
- UI は一度に2階層だけ表示し、タップで下の階層へドリルダウン（深くしても見やすい）
- 既存データは全部「ゴール」として扱われるので移行不要（`decodeIfPresent`）

### 3.2 楽しみに待つ仕掛け
1. **道のりビュー**：ゴールまでの縦タイムライン。完了したステップが埋まっていき、「今ここ」が見える
2. **節目のお祝い**：100日前・半分経過・1ヶ月前・ステップ完了時に紙吹雪＋通知
3. **テンプレート**：「結婚式」「海外旅行」「出産」「推しライブ」を選ぶと定番ステップが自動で入る（例：結婚式＝1年前 式場決定 / 6ヶ月前 前撮り / 2ヶ月前 招待状…）
4. **ワクワクメモ**（既存の期待メモを発展）：1日1行「楽しみなこと」を書ける。当日に振り返り表示
5. **思い出化**：ゴール終了後、ステップとメモを1枚の「振り返りカード」にして共有（既存の思い出セクションを拡張）

### 3.3 ウィジェット（既存：ホーム / ロック画面 / Live Activity を拡張）
| 種類 | 表示 |
|---|---|
| 小 | ゴールの残り日数＋進捗リング（ステップ完了率） |
| 中 | ゴール＋「次のステップ」3件の道のり |
| 大 / 写真 | ゴールの写真背景＋残り日数（有料） |
| インタラクティブ | ウィジェットからステップを完了チェック（iOS 17 App Intents） |
| ロック画面 / StandBy | 次のステップまで◯日 |
| Live Activity | 当日・前日に自動起動 |

## 4. 課金プラン
### 方針
結婚式・旅行は**終わりがある**ので、月額だけだとイベント後に解約される。→ **年額＋買い切り**を軸にし、月額は入口として置く。

| | 無料 | プレミアム |
|---|---|---|
| ゴール数 | 3つ | **無制限** |
| ステップ | 1ゴールにつき3つ・1階層 | **無制限・階層も無制限** |
| テンプレート | 2種 | 全部 |
| ウィジェット | 基本（小・ロック画面） | 中・大・写真・テーマ・インタラクティブ |
| 広告 | あり | なし |
| iCloud同期 / パートナー共有 | — | あり（後続フェーズ） |

### 価格案（日本）
- 月額 **¥300**
- 年額 **¥1,800**（7日間無料トライアル）← 主力
- 買い切り **¥3,600**

競合（年$15〜25、買い切り$20〜35）とほぼ同水準。

### ペイウォールを出すタイミング
- 4つ目のステップを追加しようとしたとき（「もっと細かく準備したい」と思った瞬間）
- テンプレート選択時、写真ウィジェット設定時
- 実装は RevenueCat 推奨（他プロダクトと揃える）
